SCHAGLK AI ENGINE

Interface destinée à:
- analyser le projet
- lire plusieurs fichiers
- créer/modifier des fichiers
- diagnostiquer les erreurs
- proposer/appliquer des corrections
- préparer les builds
- analyser les logs
- assister le développeur

Le moteur de modèle doit être connecté à un modèle local ou à une API.
Aucune fausse IA ne sera présentée comme fonctionnelle.
